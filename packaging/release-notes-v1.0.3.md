## v1.0.3 — 抗抖动与可观测性

这一版集中解决**网络抖动时的手感问题**（"卡一下、光标猛跳一段"），并补上一套可以直接在手机上查看的链路诊断工具。

### 修复

- **位移改走 `socket.volatile` 发送**：Socket.IO 默认会在断连期间把消息**缓冲起来**，重连后一次性补发 —— 这正是"卡一下、然后光标猛跳一段"的直接原因。现在连接未就绪时**直接丢弃旧包**，对鼠标位移来说，丢旧包远比补发正确。点击 / 拖拽 / 滚轮 / 按键**保持可靠传输不变**，丢一次点击就是一次误操作。
- **服务端位移加单帧上限**：链路卡顿后恢复时，累积位移可能在一帧内全部应用，导致光标甩飞。现按上限 1000 px 做**等比压缩**（保方向，不截断），新增 `reset_move` 事件在每次建连时清空服务端残留位移。
- **重连退避 1 秒 → 0.1 秒起步**（上限 0.5 秒，连接超时 4 秒）。每次重连都有一段命令真空期，缩短它就是直接缩小卡顿窗口。
- **启动时的推荐地址不再混入失效网卡**：地址列表现在过滤已断开的接口与 `169.254.x.x` 链路本地地址（本机实测由 14 条降到 6 条）。

### 新增

- **`/diag` 链路诊断页**：手机上直接查看
  - 当前**传输方式**（`websocket` 还是被降级成 `polling`）
  - RTT 曲线，以及平均 / P95 / 最大 / 抖动 σ
  - **空闲态与负载态的抖动对比** —— 用来判断空口竞争占多少
  - 上行到达间隔 σ（服务端侧测量，可区分上行还是下行不稳）
  - 断连 / 重连次数、屏幕刷新率
  - 页面底部给出中文判读结论
  - 负载测试走独立事件，**不会操作鼠标**
- **`/diag/stats` JSON 接口**：暴露位移队列状态与单帧上限。
- **服务端记录每次接入 / 断开日志**（含时间戳），重连次数从"靠猜"变成"可看"。
